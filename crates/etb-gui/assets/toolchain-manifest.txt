# every file in the bundled FreeBASIC, and the application embeds the result.
#
# It lives in the application binary rather than inside the bundle on purpose: a
# manifest sitting next to the compiler could be rewritten by whatever rewrote
# the compiler, so it would attest to nothing.
#
# An empty manifest means "nothing to verify", which is correct for a development
# checkout and for a build pointed at a FreeBASIC it did not ship.
#
# DO NOT COMMIT A GENERATED ONE. It describes one specific fetched bundle, so a
# checkout carrying it would report every file of any *other* bundle as missing
# and refuse to build. `cargo xtask check-hygiene` fails if hashes appear here.
